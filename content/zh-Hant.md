## 什麼是 Markdown？

Markdown 是一種**輕量級標記語言**，2004 年由 John Gruber 與 Aaron Swartz 建立。它用純文字符號標記格式，可被輕鬆轉換成 HTML。

選它的三個理由：

- **易讀**：原始碼就是純文字，不渲染也能看懂
- **易寫**：專注內容，不被排版打斷
- **通用**：GitHub、內容平台編輯器、筆記軟體（Obsidian / Notion / 語雀）等均支援

## 1. 標題

用 `#` 標記層級，數量越多，層級越深：

```markdown
# 一級標題
## 二級標題
### 三級標題
#### 四級標題
##### 五級標題
###### 六級標題
```

> 提示：`#` 後面要留一個空格。依文章結構選擇正確的標題層級，而非顯示樣式。

# 一級標題
## 二級標題
### 三級標題

---

## 2. 強調：粗體 / 斜體 / 刪除線

| 寫法 | 效果 |
| --- | --- |
| `**粗體**` | **粗體** |
| `*斜體*` | *斜體* |
| `~~刪除線~~` | ~~刪除線~~ |
| `***粗斜體***` | ***粗斜體*** |
| `` `行內程式碼` `` | `行內程式碼` |

也可以**自由組合**：`**粗體裡帶 *斜體* 和 ~~刪除~~**` → **粗體裡帶 *斜體* 和 ~~刪除~~**

## 3. 清單

### 項目符號清單

用 `-`、`*` 或 `+` 開頭：

```markdown
- 第一項
- 第二項
- 第三項
```

- 第一項
- 第二項
- 第三項

### 編號清單

用 `數字 + .` 開頭：

```markdown
1. 第一步
2. 第二步
3. 第三步
```

1. 第一步
2. 第二步
3. 第三步

### 巢狀清單

子項目前面**縮排兩個空格**即可：

```markdown
1. 準備食材
   - 雞蛋 ×2
   - 牛奶 200ml
2. 下鍋翻炒
   - 大火 30 秒
   - 轉小火
```

1. 準備食材
   - 雞蛋 ×2
   - 牛奶 200ml
2. 下鍋翻炒
   - 大火 30 秒
   - 轉小火

### 待辦清單

在 `-` 後加 `[ ]`（未完成）或 `[x]`（已完成）：

```markdown
- [x] 學會標題
- [x] 學會清單
- [ ] 學會表格
- [ ] 學會程式碼區塊
```

- [x] 學會標題
- [x] 學會清單
- [ ] 學會表格
- [ ] 學會程式碼區塊

> 提示：`-` `[` `]` 後面要留一個空格。

## 4. 連結

### 行內式

```markdown
[顯示文字](連結位址 "可選標題")
```

例如：造訪 [KylinTech 頻道](https://www.youtube.com/@KylinTech "YouTube 頻道")。

### 自動連結

```markdown
<https://www.youtube.com/@KylinTech>
```

用尖括號包住 URL，直接顯示成連結：

<https://www.youtube.com/@KylinTech>

## 5. 圖片

語法是連結前面加一個 `!`：

```markdown
![替代文字](圖片位址)
```

範例（本教學內建一張本機 SVG 圖片，無需連網即可顯示）：

> 提示：圖片位址可以是網路 URL，也可以是相對路徑。替代文字在圖片載入失敗時會顯示出來。

## 6. 引用

用 `>` 開頭，多行引用每行都要加：

```markdown
> 學而不思則罔，思而不學則殆。
>
> —— 孔子
```

> 學而不思則罔，思而不學則殆。
>
> —— 孔子

`>` 可以**層層巢狀**，實現多層引用：

> 第一層
> > 第二層
> > > 第三層

## 7. 程式碼

### 行內程式碼

用反引號包住：`` `print("hello")` `` → `print("hello")`

### 程式碼區塊

用三個反引號圍住程式碼

> 程式碼區塊務必標註語言（如 ```python），能啟用語法高亮，大幅提升程式碼的可讀性

````markdown
```python
def greet(name):
    """向某人問好"""
    return f"你好，{name}！"

print(greet("世界"))
```
````

呈現效果：

```python
def greet(name):
    """向某人問好"""
    return f"你好，{name}！"

print(greet("世界"))
```

再來看一段 JavaScript：

```javascript
const items = ["蘋果", "香蕉", "橘子"];
items.map((v) => console.log(v));
```

以及一段命令列：

```bash
git init
git add .
git commit -m "初次提交"
```

## 8. 表格

用 `|` 分欄，`-` 分隔表頭。冒號決定對齊方式：

```markdown
| 功能 | 左對齊 | 右對齊 | 置中 |
| :--- | :--- | ---: | :---: |
| 標題 | `#` | 支援 6 級 | ✓ |
| 清單 | `-` / `1.` | 可巢狀 | ✓ |
| 程式碼 | 反引號 | 高亮 | ✓ |
```

| 功能 | 左對齊 | 右對齊 | 置中 |
| :--- | :--- | ---: | :---: |
| 標題 | `#` | 支援 6 級 | ✓ |
| 清單 | `-` / `1.` | 可巢狀 | ✓ |
| 程式碼 | 反引號 | 高亮 | ✓ |

三個以上 `-`、`*` 或 `_` 單獨成行：

```markdown

```

## 10. 跳脫字元

想讓標記符號**按原樣顯示**，前面加反斜線 `\`：

```markdown
\*這不是斜體\*
\# 這不是標題
```

\*這不是斜體\*
\# 這不是標題

---

## 11. 最佳實務

1. **標題層級**：`#` 只留一個（即文章標題），正文從 `##` 開始
2. **統一符號**：項目符號清單建議用 `-` 或全程用 `*`，別 `-` `*` `+` 混用
3. **程式碼圍欄**：程式碼區塊前後各留一個空行，相容性最好
