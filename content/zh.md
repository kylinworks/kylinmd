## 什么是 Markdown？

Markdown 是一种**轻量级标记语言**，2004 年由 John Gruber 与 Aaron Swartz 创建。它用纯文本符号标记格式，可被轻松转换成 HTML。

选它的三个理由：

- **易读**：源码就是纯文本，不渲染也能看懂
- **易写**：专注内容，不被排版打断
- **通用**：GitHub、公众号编辑器、笔记软件（Obsidian / Notion / 语雀）等均支持

## 1. 标题

用 `#` 标记级别，数量越多，级别越低：

```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```

> 提示：`#` 后面要留一个空格。依据文章结构选择正确的标题，而非显示样式。

# 一级标题
## 二级标题
### 三级标题

## 2. 强调：粗体 / 斜体 / 删除线 / 高亮

| 写法 | 效果 |
| --- | --- |
| `**加粗**` | **加粗** |
| `*斜体*` | *斜体* |
| `~~删除线~~` | ~~删除线~~ |
| `==高亮==` | ==高亮== |
| `***粗斜体***` | ***粗斜体*** |
| `` `行内代码` `` | `行内代码` |

也可以**自由组合**：`**粗体里带 *斜体* 和 ~~删除~~**` → **粗体里带 *斜体* 和 ~~删除~~**

## 3. 列表

### 无序列表

用 `-`、`*` 或 `+` 开头：

```markdown
- 第一项
- 第二项
- 第三项
```

- 第一项
- 第二项
- 第三项

### 有序列表

用 `数字 + .` 开头：

```markdown
1. 第一步
2. 第二步
3. 第三步
```

1. 第一步
2. 第二步
3. 第三步

### 嵌套列表

子项前面**缩进两个空格**即可：

```markdown
1. 准备食材
   - 鸡蛋 ×2
   - 牛奶 200ml
2. 下锅翻炒
   - 大火 30 秒
   - 转小火
```

1. 准备食材
   - 鸡蛋 ×2
   - 牛奶 200ml
2. 下锅翻炒
   - 大火 30 秒
   - 转小火

### 任务列表

在 `-` 后加 `[ ]`（未完成）或 `[x]`（已完成）：

```markdown
- [x] 学会标题
- [x] 学会列表
- [ ] 学会表格
- [ ] 学会代码块
```

- [x] 学会标题
- [x] 学会列表
- [ ] 学会表格
- [ ] 学会代码块

> 提示：`-` `[` `]` 后面要留一个空格。

## 4. 链接

### 行内式

```markdown
[显示文字](链接地址 "可选标题")
```

例如：访问 [KylinTech 频道](https://www.youtube.com/@KylinTech "YouTube 频道")。

### 自动链接

```markdown
<https://www.youtube.com/@KylinTech>
```

用尖括号包住 URL，直接显示成链接：

<https://www.youtube.com/@KylinTech>

## 5. 图片

语法是链接前面加一个 `!`：

```markdown
![替代文字](图片地址)
```

示例（本教程内置了一张本地 SVG 图片，无需联网即可显示）：

![Markdown image example](assets/markdown-demo.svg)

> 提示：图片地址可以是网络 URL，也可以是相对路径。替代文字在图片加载失败时会显示出来。

## 6. 引用

用 `>` 开头，多行引用每行都要加：

```markdown
> 学而不思则罔，思而不学则殆。
>
> —— 孔子
```

> 学而不思则罔，思而不学则殆。
>
> —— 孔子

`>` 可以**层层嵌套**，实现多级引用：

> 第一层
> > 第二层
> > > 第三层

## 7. 代码

### 行内代码

用反引号包裹：`` `print("hello")` `` → `print("hello")`

### 代码块

用三个反引号围住代码

> 代码块务必标注语言（如 ```python），能启用语法高亮，大幅提升代码的可读性

````markdown
```python
def greet(name):
    """向某人问好"""
    return f"你好，{name}！"

print(greet("世界"))
```
````

渲染效果：

```python
def greet(name):
    """向某人问好"""
    return f"你好，{name}！"

print(greet("世界"))
```

```javascript
const items = ["苹果", "香蕉", "橙子"];
items.map((v) => console.log(v));
```

以及一段命令行：

```bash
git init
```

## 8. 表格

用 `|` 分列，`-` 分隔表头。冒号决定对齐方式：

```markdown
| 功能 | 左对齐 | 右对齐 | 居中 |
| :--- | :--- | ---: | :---: |
| 标题 | `#` | 支持 6 级 | ✓ |
| 列表 | `-` / `1.` | 可嵌套 | ✓ |
| 代码 | 反引号 | 高亮 | ✓ |
```

| 功能 | 左对齐 | 右对齐 | 居中 |
| :--- | :--- | ---: | :---: |
| 标题 | `#` | 支持 6 级 | ✓ |
| 列表 | `-` / `1.` | 可嵌套 | ✓ |
| 代码 | 反引号 | 高亮 | ✓ |

## 9. 分割线

三个及以上 `-`、`*` 或 `_` 单独成行：

```markdown
---
```

## 10. 转义字符

想让标记符号**按原样显示**，前面加反斜杠 `\`：

```markdown
\*这不是斜体\*
\# 这不是标题
```

\*这不是斜体\*
\# 这不是标题

---

## 11. 最佳实践

1. **标题层级**：`#` 只留一个（即文章题目），正文从 `##` 开始
2. **统一符号**：无序列表建议用 `-` 或全程用 `*`，别 `-` `*` `+` 混用
3. **代码围栏**：代码块前后各留一个空行，兼容性最好
