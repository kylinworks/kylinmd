Markdown 完全入門指南

這是一份可直接複製修改的繁體中文 Markdown 教學。
你現在看到的預覽，正是左邊這份原始碼的呈現結果。改一改左邊，右邊立刻變——邊看邊練，幾分鐘就能上手。

什麼是 Markdown？

Markdown 是一種輕量級標記語言，2004 年由 John Gruber 與 Aaron Swartz 建立。它用純文字符號標記格式，可被輕鬆轉換成 HTML。

選它的三個理由：

  • 易讀：原始碼就是純文字，不渲染也能看懂
  • 易寫：專注內容，不被排版打斷
  • 通用：GitHub、內容平台編輯器、筆記軟體（Obsidian / Notion / 語雀）等均支援

1. 標題

用 # 標記層級，數量越多，層級越深：

# 一級標題
## 二級標題
### 三級標題
#### 四級標題
##### 五級標題
###### 六級標題

提示：# 後面要留一個空格。依文章結構選擇正確的標題層級，而非顯示樣式。

2. 強調：粗體 / 斜體 / 刪除線 / 標記

寫法 效果
**粗體** 粗體
*斜體* 斜體
~~刪除線~~ 刪除線
==標記== 標記
***粗斜體*** 粗斜體
`行內程式碼` 行內程式碼

也可以自由組合：**粗體裡帶 *斜體* 和 ~~刪除~~** → 粗體裡帶 斜體 和 刪除

3. 清單

項目符號清單

用 -、* 或 + 開頭：

- 第一項
- 第二項
- 第三項
  • 第一項
  • 第二項
  • 第三項

編號清單

用 數字 + . 開頭：

1. 第一步
2. 第二步
3. 第三步
  1. 第一步
  2. 第二步
  3. 第三步

巢狀清單

子項目前面縮排兩個空格即可：

1. 準備食材
   - 雞蛋 ×2
   - 牛奶 200ml
2. 下鍋翻炒
   - 大火 30 秒
   - 轉小火
  1. 準備食材
    • 雞蛋 ×2
    • 牛奶 200ml
  2. 下鍋翻炒
    • 大火 30 秒
    • 轉小火

待辦清單

在 - 後加 [ ]（未完成）或 [x]（已完成）：

- [x] 學會標題
- [x] 學會清單
- [ ] 學會表格
- [ ] 學會程式碼區塊
  • 學會標題
  • 學會清單
  • 學會表格
  • 學會程式碼區塊

提示：- [ ] 後面要留一個空格。

7. 程式碼

行內程式碼

用反引號包住：`print("hello")` → print("hello")

程式碼區塊

用三個反引號圍住程式碼

程式碼區塊務必標註語言（如 ```python），能啟用語法高亮，大幅提升程式碼的可讀性

```python
def greet(name):
    """向某人問好"""
    return f"你好，{name}！"

print(greet("世界"))
```

呈現效果：

def greet(name):
    """向某人問好"""
    return f"你好，{name}！"

print(greet("世界"))

8. 表格

用 | 分欄，- 分隔表頭。冒號決定對齊方式：

| 功能 | 左對齊 | 右對齊 | 置中 |
| :--- | :--- | ---: | :---: |
| 標題 | `#` | 支援 6 級 | ✓ |
| 清單 | `-` / `1.` | 可巢狀 | ✓ |
| 程式碼 | 反引號 | 高亮 | ✓ |
功能 左對齊 右對齊 置中
標題 # 支援 6 級 ✓
清單 - / 1. 可巢狀 ✓
程式碼 反引號 高亮 ✓

三個以上 -、* 或 _ 單獨成行：

---

10. 跳脫字元

想讓標記符號按原樣顯示，前面加反斜線 \：

\*這不是斜體\*
\# 這不是標題

*這不是斜體*
# 這不是標題

11. 最佳實務

  1. 標題層級：# 只留一個（即文章標題），正文從 ## 開始
  2. 統一符號：項目符號清單建議用 - 或全程用 *，別 - * + 混用
  3. 程式碼圍欄：程式碼區塊前後各留一個空行，相容性最好
